第六步：录入产品数据

待完成

在 Studio 后台录入你的产品数据。目前 Sanity 中有 0 条产品数据，网站显示的是 products.js 中的默认数据。

6.1 打开 Studio

方式一（本地）：确保终端在 sanity 目录下运行 npm run dev，浏览器打开 http://localhost:3333

方式二（在线）：如果你已完成第七步部署了在线 Studio，直接访问你的 xxx.sanity.studio 地址

6.2 创建新产品

  1. 左侧导航点击 Product
  2. 点击右上角 Create new 按钮
  3. 进入产品编辑表单

6.3 填写产品信息

表单包含以下字段，逐一填写：

字段 说明 示例
Product Name产品全名Electric Mountain Bike
Product URL SlugURL 标识，点 "Generate" 自动生成electric-mountain-bike
Model Number型号Model M-01
Category选择 Electric Bike 或 Electric ScooterElectric Bike
Sub-Category ID内部筛选用 ID（见下方对照表）mountain
Sub-Category Label显示标签Mountain E-Bike
Show on Homepage勾选后显示在首页精选勾选
Display Order排序数字，越小越靠前1
Badge可选标签文字New
Key Feature核心卖点Full Suspension
Motor电机（卡片摘要）750W Brushless Hub
Battery电池（卡片摘要）48V 15Ah
Range续航（卡片摘要）80 km

6.4 上传产品图片

在 Main Product Image 区域，点击上传按钮，选择本地图片文件上传。

建议图片尺寸：800x600 或更大，JPG/PNG/WebP 格式，单张不超过 5MB。

如果你更想用外部图片 URL 而非上传文件，在 Main Image URL (Alternative) 字段填写图片链接即可，该字段优先级高于上传的图片。

6.5 添加技术参数

在 Technical Specifications 区域：

  1. 点击 Add item
  2. Spec Name 填写参数名，如 Motor
  3. Spec Value 填写参数值，如 750W Brushless Hub Motor
  4. 继续点击 Add item 添加更多参数

建议参数：Motor、Battery、Range、Max Speed、Frame、Weight、Tire Size、Brakes、Charging Time 等

6.6 添加产品图库

在 Product Gallery Images 区域，点击上传多张产品图片。

这些图片会显示在产品详情页的 Gallery 板块。建议上传 3-6 张不同角度的产品图。

6.7 添加产品特性

在 Key Features 区域：

  1. 点击 Add item
  2. Icon：从下拉菜单选择图标（Motor、Battery、Suspension、Brake、Frame、Display、Speed、Foldable、Range）
  3. Feature Title：如 750W Hub Motor
  4. Feature Description：简要描述该特性
  5. 继续添加更多特性

6.8 保存并发布

填写完成后，点击右上角 Publish 按钮发布产品。

重要：未发布的产品是 Draft 状态，前端不会显示。一定要点 Publish。

第七步：部署 Sanity Studio（在线后台）

待完成

目前 Studio 只能在你本地电脑运行。部署到云端后，你可以在任何浏览器访问后台管理产品，无需本地运行。

7.1 部署 Studio

在终端中，确保仍在 sanity 目录下，运行：

cd sanity
npx sanity deploy

7.2 设置 Studio 域名

系统会提示你输入 Studio 的域名前缀：

Write your Studio hostname []
aile-cms

部署完成后你会获得一个在线 Studio 地址：

https://aile-cms.sanity.studio

7.3 使用在线 Studio

  • 在任何电脑/手机的浏览器打开该地址即可管理产品
  • 支持多人协作（免费版支持 3 个用户）
  • 修改后即时生效，无需重新部署网站
  • Studio 地址也可以分享给团队成员
部署好处：部署后你不再需要每次本地运行 npm run dev。直接在浏览器打开 https://aile-cms.sanity.studio 就能管理所有产品数据。
