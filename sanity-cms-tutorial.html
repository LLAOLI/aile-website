第一步：注册 Sanity 账号并创建项目

STEP 1

1.1 注册账号

访问 Sanity 官网，点击右上角 Sign up。

你可以选择以下注册方式：

  • Google 账号直接登录（推荐，最快）
  • GitHub 账号登录
  • 邮箱注册

1.2 创建新项目

登录后进入管理面板，点击 New Project。

  1. 输入项目名称：aile-cms
  2. 项目描述可留空
  3. 选择订阅计划：选 Free（免费版完全够用）
  4. 点击 Create project

1.3 创建数据集

创建项目后，Sanity 会自动创建一个名为 production 的数据集，无需额外操作。

免费额度说明：免费版包含 3 个用户席位、10,000 条文档、每月 100 万次 API 请求、10GB 资产存储。对你的产品目录来说完全够用。

第二步：获取 Project ID

STEP 2

2.1 找到你的 Project ID

在 Sanity 管理面板中，点击你刚创建的项目，进入项目详情页。你会看到一段类似这样的信息：

Project ID:  a1b2c3d4e5f6
Dataset:     production

把 Project ID 复制保存，后续步骤需要用到。

注意：Project ID 是公开信息，不是密钥。前端代码里直接使用 Project ID 是正常的，Sanity 的安全性通过 CORS 和 API 权限控制。

第三步：配置前端代码

STEP 3

3.1 修改 sanity-config.js

用编辑器打开项目目录下的 js/sanity-config.js 文件。

找到第 6 行，把 YOUR_PROJECT_ID 替换为你的实际 Project ID：

修改前：
var SANITY_CONFIG = {
  projectId: 'YOUR_PROJECT_ID',
  dataset: 'production',
  apiVersion: '2024-01-01',
};

修改后（示例）：
var SANITY_CONFIG = {
  projectId: 'a1b2c3d4e5f6',
  dataset: 'production',
  apiVersion: '2024-01-01',
};

3.2 修改 sanity/sanity.config.js

打开 sanity/sanity.config.js，同样替换 Project ID：

修改前：
projectId: 'YOUR_PROJECT_ID',

修改后：
projectId: 'a1b2c3d4e5f6',
两个文件都要改：前端配置文件 js/sanity-config.js 和 Studio 配置文件 sanity/sanity.config.js 都需要替换。

第四步：安装并启动 Sanity Studio

STEP 4

4.1 前置要求

确保你的电脑已安装 Node.js（v18 以上）。如果没有安装：

  • 访问 nodejs.org 下载 LTS 版本
  • 安装时勾选所有默认选项
  • 安装完成后打开终端，运行 node -v 验证安装

4.2 安装依赖

打开终端（Windows 用 PowerShell），进入项目的 sanity 目录：

cd "C:\Users\你的用户名\AppData\Roaming\TRAE SOLO CN\ModularData\ai-agent\work-mode-projects\6aaa030810d3ec62e193ff89\sanity"

npm install

等待安装完成（大约 1-2 分钟）。

4.3 启动 Studio

npm run dev

启动后会显示：

Sanity Studio is running at http://localhost:3333

在浏览器打开 http://localhost:3333，你会看到 Sanity Studio 后台界面：

左侧导航有 "Product" 文档类型，点击后可以创建和管理产品。

首次启动可能需要登录：如果 Studio 提示登录，使用你注册 Sanity 的账号登录即可。Studio 会自动关联你在第二步创建的项目。

第五步：配置 CORS 跨域访问

STEP 5

由于你的网站和 Sanity API 在不同域名下，需要在 Sanity 中配置 CORS 允许你的网站访问数据。

5.1 进入 CORS 设置页面

  1. 访问 Sanity 管理面板
  2. 点击你的项目 aile-cms
  3. 顶部菜单选择 API
  4. 点击 CORS Origins 标签

5.2 添加允许的域名

点击 Add CORS Origin，依次添加以下来源：

# 本地开发（如果你在本地预览网站）
http://localhost:5500
http://127.0.0.1:5500

# Cloudflare Pages 部署后替换为你的实际域名
https://aile-website.pages.dev

# Vercel 部署后替换为你的实际域名
https://aile-website.vercel.app

# 自定义域名（如果绑定了）
https://ailebicycle.com
设置说明：
  • Allowed Origin：填写你的网站域名（不含末尾斜杠）
  • Allowed Methods：勾选 GET 即可（前端只需读取数据）
  • Credentials：不需要勾选
重要：每增加一个新的部署域名，都需要在这里添加对应的 CORS Origin。否则浏览器会拦截 Sanity API 请求，导致产品数据无法加载（此时网站会自动 fallback 到 products.js 中的默认数据）。

第六步：录入产品数据

STEP 6

在 Studio 后台（http://localhost:3333）录入你的产品数据。

6.1 创建新产品

  1. 左侧导航点击 Product
  2. 点击右上角 Create new 按钮
  3. 进入产品编辑表单

6.2 填写产品信息

表单包含以下字段，逐一填写：

6.3 上传产品图片

在 Main Product Image 区域，点击上传按钮，选择本地图片文件上传。

建议图片尺寸：800x600 或更大，JPG/PNG/WebP 格式，单张不超过 5MB。

如果你更想用外部图片 URL 而非上传文件，在 Main Image URL (Alternative) 字段填写图片链接即可，该字段优先级高于上传的图片。

6.4 添加技术参数

在 Technical Specifications 区域：

  1. 点击 Add item
  2. Spec Name 填写参数名，如 Motor
  3. Spec Value 填写参数值，如 750W Brushless Hub Motor
  4. 继续点击 Add item 添加更多参数

建议参数：Motor、Battery、Range、Max Speed、Frame、Weight、Tire Size、Brakes、Charging Time 等

6.5 添加产品图库

在 Product Gallery Images 区域，点击上传多张产品图片。

这些图片会显示在产品详情页的 Gallery 板块。建议上传 3-6 张不同角度的产品图。

6.6 添加产品特性

在 Key Features 区域：

  1. 点击 Add item
  2. Icon：从下拉菜单选择图标（Motor、Battery、Suspension、Brake、Frame、Display、Speed、Foldable、Range）
  3. Feature Title：如 750W Hub Motor
  4. Feature Description：简要描述该特性
  5. 继续添加更多特性

6.7 保存

填写完成后，点击右上角 Publish 按钮发布产品。

未发布的产品是 Draft 状态，前端不会显示。一定要点 Publish。

第七步：部署 Sanity Studio（在线后台）

STEP 7

目前 Studio 只能在你本地电脑运行。部署到云端后，你可以在任何浏览器访问后台管理产品。

7.1 部署 Studio

在终端中，确保仍在 sanity 目录下，运行：

npx sanity deploy

7.2 设置 Studio 域名

系统会提示你输入 Studio 的域名前缀：

Write your Studio hostname []
aile-cms

部署完成后你会获得一个在线 Studio 地址：

https://aile-cms.sanity.studio

7.3 使用在线 Studio

  • 在任何电脑/手机的浏览器打开该地址即可管理产品
  • 支持多人协作（免费版支持 3 个用户）
  • 修改后即时生效，无需重新部署网站
  • Studio 地址也可以分享给团队成员
部署后也需要配置 CORS：如果你是在 Studio 在线后台进行数据管理，不需要额外 CORS 配置。但如果你的网站部署在 Cloudflare/Vercel 上，仍然需要按第五步配置 CORS 允许网站域名访问 Sanity API。

第八步：重新部署网站

STEP 8

8.1 重新打包

配置好 js/sanity-config.js 中的 projectId 后，需要重新打包并上传网站。

网站目录下的文件结构应如下：

aile-website/
├── index.html
├── about.html
├── products.html
├── product-detail.html
├── contact.html
├── css/
│   └── styles.css
└── js/
    ├── main.js
    ├── products.js
    ├── forms.js
    └── sanity-config.js  ← 已修改 projectId 的文件

8.2 上传到 Cloudflare Pages

  1. 重新打包 zip 文件（包含所有 HTML + css/ + js/）
  2. Cloudflare Dashboard → Workers & Pages → 你的项目
  3. 点击 Create new deployment
  4. 上传新的 zip 文件 → Deploy

8.3 上传到 Vercel

  1. Vercel Dashboard → 你的项目
  2. 点击 Redeploy 或拖拽上传新文件
  3. 等待部署完成

8.4 验证

部署完成后，访问你的网站：

  • 首页精选产品应显示你在 Sanity 中标记为 "Show on Homepage" 的产品
  • 产品列表页应显示所有已发布的产品
  • 点击产品卡片应跳转到产品详情页，显示你在 Sanity 中录入的参数和图片
如果网站仍然显示旧的默认数据：
  1. 检查 js/sanity-config.js 中的 projectId 是否已替换
  2. 检查 Sanity 后台产品是否已 Publish（不能是 Draft）
  3. 检查 CORS 是否已添加你的网站域名
  4. 打开浏览器开发者工具（F12）→ Console 面板查看是否有错误信息
  5. 打开 Network 面板查看 Sanity API 请求是否返回了数据

常见问题

Q: 不配置 Sanity，网站能正常工作吗？

可以。当 sanity-config.js 中 projectId 仍为 YOUR_PROJECT_ID 时，网站会自动使用 products.js 中的默认产品数据，功能完全正常。配置好 Sanity 后自动切换为从 CMS 拉取数据。

Q: Sanity API 请求失败会怎样？

如果网络异常或 CORS 未配置，loadProducts() 会捕获错误并自动 fallback 到 products.js 中的默认数据。网站不会白屏或报错。

Q: 免费版够用吗？

完全够用。免费版包含 3 个用户、10,000 条文档、10GB 图片存储、每月 100 万次 API 请求。对于管理几十个产品来说绰绰有余。

Q: 图片存在哪里？

直接上传到 Sanity Studio 的图片会存储在 Sanity 的 CDN 上，前端通过 cdn.sanity.io 拉取，自动优化和压缩。也可以使用外部 URL（如自己的 CDN 或其他图床）。

Q: 如何让团队成员管理产品？

在 Sanity 管理面板 → 你的项目 → Members → Invite，输入对方邮箱即可邀请。免费版支持 3 个用户。对方登录后可以访问在线 Studio（第七步部署的地址）管理产品。

Q: 修改产品后多久生效？

在 Studio 中 Publish 产品后立即生效。下次用户访问网站时会拉取最新数据。由于浏览器缓存，用户可能需要刷新页面才能看到更新。

Q: 可以批量导入产品吗？

可以。通过 Sanity 的 Script 或 CLI 工具可以批量导入 JSON 数据。如果你有大量产品需要导入，告诉我你的数据格式，我可以帮你写导入脚本。
